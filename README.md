# Day 6 - JavaScript Core Concepts

As part of my 30 Day Placement Preparation Challenge, I focused on
some of the most important JavaScript concepts that frequently appear
in interviews and real-world development.

## Topics Covered

- Arrays and Array Methods
- map()
- filter()
- reduce()
- forEach()
- find()
- sort()
- slice()
- Function Declaration
- Function Expression
- Arrow Functions
- Callback Functions
- Closures
- Higher-Order Functions
- Objects
- `this` keyword

## Key Learning

JavaScript is not only about writing syntax. Understanding how
functions work together with arrays, callbacks, closures and
higher-order functions is important for writing reusable and
maintainable code.
